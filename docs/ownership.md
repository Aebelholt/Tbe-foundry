# Ownership ledger

Tracks capabilities (a rule, constant, table, or check) that have been
found duplicated across this codebase, and states one canonical owner going
forward. See CLAUDE.md's "Ownership discipline for shared rules" for the
process this file supports: before touching anything that isn't pure
presentation, check here first, and add a row if you find a new duplicate.

Foundry macros can't `import`, so "owner" for macro-reachable logic means a
value exposed on `game.thebrokenempires.rules.*` (set at system init) that
macros read at runtime, not a module macros can't reach.
