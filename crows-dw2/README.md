# crows-dw2

A solo Crows (MCDM Playtest 2) game with an LLM Ref, hardened for the failure modes of LLM refereeing, plus the research behind it.

- **Play:** `PLAY.md`.
- **Rules to load:** `crows_01_system_layer_v1.2.md` (v1 + Amendment 1 + wilderness supplement), `crows_00_chassis_v3.md`, `crows_02_source_index.md`, `crows_06_hot_card_v1.2.md`, `03_director_sealed_template.md`, `engine/`.
- **Research and decisions:** `out/results.md` (scorecard and verdict), `out/phase1_report.md` (combat and Threat simulations), `out/changelog.md`, `out/crows_01_system_layer_amendment.md`, `out/weird_wyld_notes.md`, `out/sim/`, `out/transcripts/` (20+ Ref trials with audit sheets).
- **Original v1 files** are kept unchanged: `crows_01_system_layer.md`, `crows_06_hot_card.md`.

The Crows books and the *Into the Wyrd and Wild* book are copyrighted. This repo contains only the author's rules text, paraphrased wilderness tables (private use) and tools. The extracted book text under `src/` and `crows/src/` is ignored; extract your own with `tools/extract_sources.py`.
